## 루프 규칙
1. 오케스트레이터는 한 턴에 ① 「답변 N」 기록 ② 「질문 N+1」 작성 + 같은 글로 `docs/interview/보낼글.txt` 덮어쓰기 — **여기까지 가장 먼저** ③ 답변 분해 후 PROBLEM 반영(`[답변N]`) ④ STRATEGY 갱신(M1) ⑤ 커밋 ⑥ 사용자 설명 다섯 칸을 모두 한다. 사용자는 `보낼글.txt` 가 바뀌면 바로 ⌘A·⌘C → DM.
2. 질문 수 제한은 없다. 문제 정의서가 찰 때까지 계속한다.
3. 이미 답 받은 질문은 재전송하지 않는다. 쓰기 전에 직전 답변을 다시 읽는다.
4. 사용자가 잘라 보낸 것은 사용자가 한 줄만 알리면 에이전트가 DECISIONS 에 기록한다.

## 질문 글 규칙
- 존댓말 메신저 구어체. 보고서·요약 말투 금지. 앞 답변의 말을 받아서 시작한다(「아까 ~라고 하셨는데요」). 상대가 쓴 용어를 그대로 따라 쓴다.
- 번호 목록으로 구조화하는 것은 허용한다. 굵은 글씨·소제목 같은 꾸밈은 쓰지 않는다.
- 모양 예:

```
말씀 감사합니다. 아까 월말에 몰린다고 하신 부분이 마음에 걸려서요, 다음과 같은 사항이 궁금해요. 하나씩 답해주시면 감사드릴게요.
1. ~
2. ~
```
