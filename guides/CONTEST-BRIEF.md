## 확정 (10-26 메일+첨부 3부 문면 · 10-29 접속 링크 메일)

- **10-29 운영 메일(가이드 3종과 다르면 이 메일이 우선)**: 권장 모델 **6.1 Sol · 5.6 Terra · 6.0 Luna** 셋. **Codex 버전 업데이트 금지** — 업데이트 권유가 떠도 제공 버전 그대로. 토큰은 과제에 충분히 주되 **AI 사용량과 활용 과정이 평가에 참고될 수 있다** — 목적에 맞게 효율적으로(같은 일을 여러 탭에 중복시키지 않는다). 공개 저장소의 지침·Skill·하네스·템플릿·코드는 활용 가능하나 **그 저장소는 공개 상태여야 하고 2차 예선 결과 통지 전까지 공개 유지**, 비공개 저장소 사용·외부 자료로 결과물 통째 대체 불가, 사용 자료·작업 이력은 검토 대상. 09:40 까지 접속(시작 공지 없음, 10:00 에 직접 시작), 09:40 추가 공지 메일. Chrome. 블루투스 키보드·마우스 불가(유선 또는 노트북 내장). 장애는 시험 환경 안 문의 버튼에 발생 시각·증상.

- 시간: 2026-10-31(토) 09:40 까지 접속 → 10:00 과제 시작 = 작업 타이머 시작. 신분증·스마트 안경 검사·Proctor 폰 거치는 그 뒤라 빌드 시간을 먹는다.
- 과제 풀이 최대 180분 → 제출물 확정(이후 파일 수정·재제출 없음) → 문항 준비 대기 약 5분(최대 10분) → 후속 서술형 6문항 × 5분. 14:00 전체 강제 종료, 늦게 입장해도 연장 없음. 일찍 제출 가능. 종료 10분 전 제출 시작 권장.
- AI 도구: 응시 환경이 제공한 Codex 만. 개인 API 키·Claude Code·별도 모델 연결 금지. 권장 모델은 위 10-29 메일의 셋(Sol 6.1 · Terra 5.6 · Luna 6.0), Astra 는 제한. 토큰 사용량을 추적하며 간접 평가에 쓰일 수 있다. Codex 는 승인 요청이 기본이라 내가 눌러야 진행된다.
- 반입: 개인 PC 파일 업로드 불가(비공개 Skill 포함). 일반 공개 Skill · GitHub 공개 저장소 · MCP · Plugin 은 과제용으로 git clone·다운로드 가능. 외부 브라우저 직접 접근 금지, 정보 습득은 플랫폼 안 AI 로.
- Git Push 불가. 외부 전송은 모니터링된다. 제출 직전 결과물 통째 대체는 부정행위 검토 대상.
- 화면: 개발자용 웹 IDE(Cofa Desktop 아님). 좌측 탐색기·Browser·MCP, 중앙 에디터·터미널(탭·분할), 우측 메신저(Cofa Helper + 「업무 담당자」 실무자 에이전트 DM). Browser 미리보기는 서버를 `0.0.0.0` 에 바인딩해야 연결된다. MCP 탭에서 JSON 편집 → Codex 설정 반영. 업무 맥락은 실무자 에이전트에 묻는다.
- **평가 방향(상세 가이드 1장, 이미지 판독 10-29 — 텍스트 추출본엔 빠져 있었다)**: 「**기술·인지·의도의 세 가지 축**으로 AI 활용 역량을 평가. 구현 결과와 함께 문제를 이해하고 AI 에 맥락·지시를 제공한 과정, AI 제안의 채택·수정·거절 이유, 결과 검증과 한계에 대한 판단을 살핀다. **실무자 에이전트와의 대화 내용도 평가에 반영될 수 있다**.」 축 이름은 확정, 항목·배점은 미공개.
- 채점 표면 문구: 「수행 과정과 결과물 + 본인 이해도」. 「에이전트 응답시간을 고려한 위임과 시간 안배도 AI 활용 역량의 일부」.
- 제출 문서(계획·협업 기록)는 AI 와 같이 써도 불이익 없다. 「선택한 판단과 근거 · 검증 결과 · 남은 한계」가 담기면 된다.
- 서술형: 제출물 + 작업 기록으로 생성. AI 사용 금지·복사 붙여넣기 금지·이전 문항 복귀 불가. 「질문의 전제와 구현이 다르면 차이를 밝히고 본인의 작업을 설명하라」 — 전제 오류 지적이 허용된다.
- 수집 데이터 4종: 에이전트 대화 · 터미널 세션 · AI 도구 설정 / git 로그 · diff · 테스트 결과 / 코드 · 계획 문서 · 협업 기록.
- 감독: 모니터 1대 · 전체화면 강제 · 캡처 단축키 감지 · 웹캠 · Proctor 폰 · 실물 신분증 · 유선 키보드 1개 · Computer Use 금지.
- 사전 체험: 10-29(목) 개별 링크 메일, 1회·15분, 평가 미반영. 과제 형식은 당일 README 가 기준(미상).
- OOM 은 구제 없음. 상단 CPU/RAM 표시를 보며 병렬 세션 수를 정한다(예시 화면 RAM 16G).
- **웹 IDE 조작(상세 가이드 5·6·7장 이미지)**:
  - **우리는 맥북으로 응시한다 — 키는 전부 맥 기준.** 터미널 붙여넣기 = **⌘V**, 복사 = 드래그 선택 뒤 **⌘C**. **control+C 는 실행 중 명령 중단**(맥에서도 control 키) — Codex·서버 탭에서 누르지 않는다. 단축키: 내용 검색 ⌘⇧F · 파일명 검색 ⌘P · 파일 안 찾기 ⌘F · 탐색기 접기 ⌘B · 저장 ⌘S.
  - 메신저(DM)는 **Enter 전송 · Shift+Enter 줄바꿈**. 여러 줄 글은 붙여넣기로 넣고 마지막에 Enter 한 번.
  - 터미널 탭 이름은 더블클릭으로 바꾼다. 서버를 띄운 탭은 닫지 않는다(프로세스도 죽는다). 연결이 끊기면 터미널의 「다시 연결」.
  - 에디터는 자동 저장. **Codex 가 고치는 파일을 에디터 탭에 열어 두면 「외부 변경 감지」 충돌**로 자동 저장이 멈춘다 → 「외부 변경 불러오기」를 고른다(에디터 내용으로 덮지 않는다). 파일 목록이 늦으면 탐색기 새로고침.
  - 파일 옆 `U`=이번 접속 뒤 새 파일, `M`=에디터에 저장 안 된 변경.
  - 입력이 없으면 작업 환경이 「비활성/일시정지」될 수 있다(타이머는 계속) — 「계속 작업」을 누르면 붙는다. 긴 대기 중 확인.
  - 제출 미리보기에는 결과물 일부만 보인다(숨김 파일·내부 도구 폴더 생략 가능) — 목록이 짧아도 정상. 최종 완료 화면에서 제출 ID·시각·파일 수·크기 확인.
  - 서술형: 문항 준비 대기는 최대 10분(자동 재시도 시 다시 시작). 첫 문항 타이머는 「문제 풀기」를 누를 때, 다음 문항은 직전 답안 제출 순간부터. 시간이 끝나면 쓰던 답이 자동 확정.
  - 화장실 등 자리 이탈 안내는 당일 09:50 별도 메일.

## 추정 (7월 코파톤 = 같은 Cofa Probe 실측 — 2차에서 다를 수 있음)

- 3축 이름은 2차에서도 같다(위 확정). 14항목 배점은 공개되지 않았다 — 코파톤 구조를 참고만 한다.
- 판정은 **칸 단위 대조**일 가능성이 크다. 문서에 쓴 주장마다 코드 라인이나 실행 증거를 붙인다. 문서에만 있는 기능은 감점으로 본다.
- 충족 신호: 완료 조건·수용 기준을 적은 프롬프트 · 실패→수정→같은 검증으로 재통과 · 결정 이유와 기각한 대안 · 새 세션이 이어받을 수 있는 의도 문서.
- 미충족 신호: 「알아서 잘 만들어줘」식 통째 위임 · AI 완료 보고를 검증 없이 수용 · 교과서 일반론 답변 · 없는 파일·API 인용 · 도구 남발.
- 서술형 모범 답안 형태는 코파톤 채점 화면 기준 「약점 지점 복수 → 파급 → 다음 검증」(`docs/ANSWER-FORM.md`). 2차 예시 화면은 문항 제목이 「제출 전 이해도 확인」, 예시 문항 수 5(공지는 6 — 실제 수는 응시 화면 기준). 코파톤 질문은 운영형·설계 경계형(「장애가 나면?」「결정론 부분과 AI 부분을 어떤 기준으로 나눴나?」)이었다.
