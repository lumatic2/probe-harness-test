> `AGENTS.md` 「사용자 신호」의 첫 줄이 여기를 가리킨다. 이 단계는 세팅 완료 보고에서 끝난다 — 과제 README 는 아직 읽지 않는다.

- **「세팅」** — `GitHub 의 lumatic2/probe-harness 레포를 이 폴더에 클론하고 README 대로 세팅해줘`. 작업 공간 안에 클론하고 README 「세팅」 절대로 `setup.sh` 를 돌린 뒤 **세팅 완료 보고**: `setup.sh` 가 보고 ①~④(깐 것 · 환경 · 과제 파일 · 시간 앵커)를 출력한다 — 그대로 전하고 덧붙일 것은 모델·effort 한 줄뿐, 과제 README 는 읽지 않는다. 보고 끝에 한 줄을 더 붙인다: **스킬(`$`)이 안 보이면 `/quit` → `codex` 로 다시 켠다**(세션 시작 때 스킬 목록이 고정되는 경우 — 사전 체험에서 확인 예정이라 조건부. 그래도 못 찾으면 `.agents/skills/<이름>/SKILL.md` 를 직접 읽고 그대로 한다). 덧붙이는 모델·effort 한 줄은 「effort 는 어디서나 medium · 모델은 `guides/KICKOFF.md` 「세션 편성 표」의 표준 등급(사전 체험 모델 비교로 확정)」. 마지막 줄 `다음 입력(오케): 과제 브리핑해줘`. 레포를 못 찾거나 clone 이 막히면 URL 을 손으로 넣지 않는다.
