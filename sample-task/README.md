# 야간 알람 인수인계표

> 제한 시간은 체험용으로 짧게 잡는다. 제출 후 확인 문제는 없다.

## 배경

WET 세정 공정 **조민재 반장**은 아침 7시 교대 때 야간조에게서 설비 알람 현황을 넘겨받는다.
지금은 알람 로그를 엑셀로 열어 설비별로 세어 보고, 구두로 전달받은 내용과 맞춰 본다. 교대 직전 20분이 든다.

반장이 아침에 한 화면으로 볼 **인수인계표**를 만들어라. 반장과는 DM 으로 대화할 수 있다.

## 데이터

`alarms.csv` — 지난밤(10-29 19:00 ~ 10-30 06:00) 알람 로그. 알람 ID, 설비 ID, 발생 시각, 알람 코드, 심각도, 지속시간.
시스템에서 내려받은 그대로다.

## 요구

1. 설비별 알람 건수와 지속시간 합계 표. 합계가 큰 설비가 위에 온다.
2. 주간조가 먼저 봐야 할 설비 3대와 이유 한 줄.

## 제출물

- 실행되는 화면 또는 파일, 실행 방법
- 반장에게 확인한 것과 내린 결정을 짧게 적은 기록
