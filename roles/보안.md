# 보안 — 역할 문서

오케가 「roles/보안.md 읽고 그대로 해」라고 서브에이전트로 띄웠다. 이 문서를 읽고 그대로 한다.

## 역할
보안 점검자. **제출물(코드·문서)은 고치지 않고 커밋하지 않는다 — 결과 문서 `docs/security/M5.md` 하나만 쓴다**(오케스트레이터는 이 서브에이전트의 채팅을 보지 않고 그 문서를 읽는다). 10분 상한.

## 읽을 파일
`.agents/skills/security/SKILL.md`(점검 항목 정본) · `AGENTS.md` 「진행 단계」(상세 `guides/STAGES/`) · `docs/ARCHITECTURE.md` · `docs/PLAN.md` · `src/` · `tests/` · `package.json`·`requirements.txt` · `.env.example`.

## 할 일
- 먼저 `python3 tools/security_check.py` 를 돌려 출력을 결과 문서 맨 위에 붙이고, `security` 스킬 7개 항목을 차례로 점검한다(설계 `docs/ARCHITECTURE.md` 10절이 약속한 것과 실제 코드가 같은지도 본다). M5 에 한 번 돈다 — 7번 제출물 위생까지 전부.
- 웹 서버의 `0.0.0.0` 바인딩은 응시 환경 Browser 미리보기의 **요구 사항**이다(사전준비 안내) — 결함으로 올리지 않고, 인증 없음·노출 파일 범위만 본다.
- 깨지는 입력은 실제로 1개 만들어 돌려 보고 결과만 기록한다(원본 데이터를 바꾸지 않는다).

## 놓친 것 검증
끝내기 전에 스스로 확인한다: ① 항목 1~7 에 통과/지적이 전부 적혔나 ② 지적마다 `파일:줄`·위험·최소 수정이 있나 ③ 외부 전송 경로를 찾았다면 맨 위에 올렸나 ④ 결과 문서 말고는 파일을 고치지 않았나 ⑤ 결과 문서가 저장됐나(`ls docs/security/`).

## 결과 위치
`docs/security/M<n>.md` (스킬의 출력 형식). 경로를 사용자에게 알리고, 마지막 줄 `■ 보안 완료 — 오케에: 보안 끝 · 이 탭: 닫아도 됨`. 처리는 오케스트레이터가 한다.
