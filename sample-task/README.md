# 체험 과제: 야간 알람 인수인계표

당신은 FDE로서 WET 세정 공정 조민재 반장과 함께 일하게 되었습니다.

## 상황

WET 세정 공정은 아침 7시 교대 때 야간조에게서 설비 알람 현황을 넘겨받습니다. 지금은 알람 로그를 엑셀로 열어 설비별로 세어 보고, 구두로 전달받은 내용과 맞춰 봅니다. 교대 직전 20분이 듭니다.

시스템에서 내려받은 그대로의 `alarms.csv`가 있습니다. 지난밤(10월 29일 19:00부터 30일 06:00까지)의 알람 ID, 설비 ID, 발생 시각, 알람 코드, 심각도, 지속시간이 들어 있습니다.

## 현업의 요청

> "아침에 한 화면으로 훑어볼 인수인계표가 있으면 좋겠어요. 설비마다 알람이 몇 번 울렸고 합쳐서 얼마나 오래 울렸는지 보고 싶고, 합계가 큰 설비가 위에 있었으면 해요. 그리고 주간조가 먼저 봐야 할 설비 세 대와 이유를 한 줄씩 알려 주세요."

## 현업 파트너: 조민재 반장

과제 화면의 업무 대화 채널에는 WET 세정 공정 조민재 반장이 연결되어 있습니다.

조민재 반장은 현장에서 11년을 일한 현업 담당자이고, 아침 교대 때 5분 안에 알람 현황을 훑습니다. 어떤 설비가 어떻게 울리는지, 무엇을 먼저 봐야 하는지를 자신의 업무 경험을 바탕으로 이야기합니다.

다만 조민재 반장은 개발자가 아닙니다. 어떤 도구를 써야 하는지, 데이터를 어떻게 처리해야 하는지, 화면을 어떻게 만들어야 하는지를 정해 주지 않고 업무를 현업의 언어로 설명할 뿐입니다. 조민재 반장이 이야기하는 모든 필요를 반드시 구현해야 하는 것은 아닙니다. 선택한 범위와 그 이유를 현업 담당자와 합의하는 것도 이번 체험의 일부입니다.

## 과제

조민재 반장과의 대화를 바탕으로, 야간 알람 인수인계표를 기획하고 구현하세요.

설비별 알람 건수와 지속시간 합계를 한 표로 보여 주어야 하고, 합계가 큰 설비가 위에 와야 합니다. 그 표와 함께 주간조가 먼저 봐야 할 설비 3대와 이유 한 줄을 보여 주어야 합니다. 반장에게 확인한 것과 내린 결정은 짧은 기록으로 남기고, 결과물을 어떻게 실행하는지도 적어 주세요.

어떤 방식으로 만들지는 여러분의 판단에 맡깁니다. 반장이 별도의 설명 없이도 아침에 바로 볼 수 있도록 사용하기 쉬운 화면도 함께 고민해 주세요.

## 실행 환경

결과물은 주어진 샌드박스에서 실행되어 화면 또는 파일로 확인할 수 있어야 합니다. 이 과제 환경에는 OpenAI API가 제공되지 않습니다. 외부 API 키가 필요한 방식은 쓸 수 없으니, 필요한 판단과 계산은 코드 안에서 해결하세요.
