# M0 세팅 — 「세팅」 신호를 받았을 때 (오케스트레이터)

> `roles/오케.md` 「사용자 신호」의 첫 줄이 여기를 가리킨다(세팅 요청을 받은 세션은 오케다 — **`roles/오케.md` 전체를 먼저 읽는다**, `AGENTS.md` 「역할 정하기」). 이 단계는 세팅 완료 보고에서 끝난다 — 과제 README 는 아직 읽지 않는다.

- **「세팅」** — `GitHub 의 lumatic2/probe-harness 레포를 이 폴더에 클론하고 README 대로 세팅해줘`. 작업 공간 안에 클론하고 README 「세팅」 절대로 `setup.sh` 를 돌린 뒤 **세팅 완료 보고**: `setup.sh` 가 보고 ①~④(깐 것 · 환경 · 과제 파일 · 시간 앵커)를 출력한다 — 그대로 전하고 덧붙일 것은 모델·effort 한 줄뿐, 과제 README 는 읽지 않는다. 보고 끝에 한 줄을 더 붙인다: **세팅 후 `/quit` → 같은 작업 폴더의 bash에서 `codex 실행 후 /resume`로 돌아온다**(10-30 사용자 확정). 돌아온 뒤 `$`와 `/status`를 확인한다. 스킬(`$`)이 안 보이면 `.agents/skills/<이름>/SKILL.md`를 직접 읽는다. 덧붙이는 모델·effort 한 줄은 「effort 는 어디서나 medium · 모델은 `guides/KICKOFF.md` 「세션 편성 표」의 표준 등급(사전 체험 모델 비교로 확정)」. 마지막 줄 `다음 입력: /quit → bash에서 codex 실행 후 /resume → 과제 브리핑해줘`. 레포를 못 찾거나 clone 이 막히면 URL 을 손으로 넣지 않는다.
