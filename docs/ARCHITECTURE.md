- 스캐폴드: 폴더 트리 · 시그니처만 있는 빈 파일 · 모듈별 계약 테스트(처음엔 빨강) · 통합 테스트 1개. 통합 테스트가 초록이 되는 것이 곧 관통이다 — 별도 관통 테스트를 두지 않는다.
- 검수 1차 기준 = 계약 테스트 초록, 그다음 이 문서와 대조.
- 명령: `./verify.sh "<…>"`
