# 답변 평가 기준

> 가상 문서 — 연습용으로 꾸민 규정이며 실제 사내 규정이 아닙니다.

## 1. 평가 항목

답변은 구체성, 논리성, 직무 이해, 전달력의 네 항목으로 평가한다. 각 항목은 5점 만점이며 총점은 20점이다. 총점 14점 이상이면 합격 수준으로 본다.

## 2. 위험 키워드 판정

판정은 정해진 규칙이 한다. 질문에 지정된 위험 키워드가 답변에 하나라도 나오면 해당 답변은 주의로 분류하고, 두 개 이상 나오면 재연습 대상으로 분류한다. AI 는 판정을 바꾸지 못하며 개선 제안만 쓴다.

## 3. 시간 초과

답변 시간 제한을 넘기면 전달력 항목에서 1점을 깎는다. 제한의 1.5배를 넘기면 답변을 중단시키고 다시 연습하도록 한다.

## 4. 재연습

재연습은 처음 연습한 날로부터 7일 안에 같은 질문으로 한 번 더 한다. 두 번째에도 합격 수준에 못 미치면 다른 연습 담당과 함께 답변 구성을 다시 짠다.
